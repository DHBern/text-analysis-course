# Recap: which method for which task?

An overview of the methods used so far, to help you choose for the final assignment.

## From task to method

| What do you want to do? | Method | Session |
|---|---|---|
| Find a precise pattern (dialogues, two-word names, a list of verbs) | Regular expressions | [1](session01/readme.md) |
| Compare the lexical richness of texts | TTR and MATTR | [3](session03/readme.md) |
| Prepare a text for analysis | Tokenisation, lemmatisation | [4](session04/NLP-basics.ipynb) |
| Count nouns, verbs or adjectives, or the most frequent content words | POS tagging, stop words, frequency lists | [4](session04/NLP-basics.ipynb) |
| Extract people, places and other names | Named Entity Recognition (NER) | [5](session05/readme.md) |
| Find the words that characterise each document | TF-IDF | [5](session05/BoW-TFIDF.ipynb) |
| Rank documents for a search | TF-IDF | [5](session05/BoW-TFIDF.ipynb) |
| Describe how two versions of a passage differ | Formal features, such as letter similarity | [6](session06/Variants-features.ipynb) |
| Sort texts into your categories, without giving examples | Zero-shot classification (NLI) | [7](session07/readme.md) |
| Sort texts into categories, providing examples | Few-shot prompting with an LLM | [7](session07/readme.md) |
| Find topics in a corpus, without choosing categories in advance | BERTopic | [8](session08/BERTopic.ipynb) |
